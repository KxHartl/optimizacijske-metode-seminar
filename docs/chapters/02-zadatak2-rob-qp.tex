\section{Zadatak 2: robusni kvadratni program}

\subsection{Skup nesigurnosti i robusna formulacija}

Za problem iz Zadatka 1 pretpostavlja se da koeficijenti $a_{ij}$ nisu točno poznati, nego da njihove stvarne vrijednosti leže u intervalu od $\pm 15\%$ oko nominalnih:
\begin{equation}
a_{ij} \in \left[a_{ij}^0 - 0.15|a_{ij}^0|,\ a_{ij}^0 + 0.15|a_{ij}^0|\right], \qquad i, j \in \{1, 2\}.
\label{eq:rob_interval}
\end{equation}
Uz nominalne vrijednosti $a_{11}^0 = a_{12}^0 = a_{22}^0 = -1$ i $a_{21}^0 = 1$ to daje
\begin{equation}
a_{11}, a_{12}, a_{22} \in [-1.15, -0.85], \qquad a_{21} \in [0.85, 1.15].
\end{equation}
Retke matrice ograničenja označimo s $a_1 = [a_{11}, a_{12}]^{\mathsf{T}}$ i $a_2 = [a_{21}, a_{22}]^{\mathsf{T}}$; njihovi skupovi nesigurnosti su pravokutnici
\begin{equation}
\mathcal{P}_1 = [-1.15, -0.85] \times [-1.15, -0.85], \qquad
\mathcal{P}_2 = [0.85, 1.15] \times [-1.15, -0.85].
\end{equation}

Traži se $x$ koji minimizira istu funkciju cilja i zadovoljava ograničenja za \emph{svaku} realizaciju koeficijenata:
\begin{equation}
\min_{x} \ \tfrac{1}{2} x^{\mathsf{T}} Q x + c^{\mathsf{T}} x
\quad \text{uz} \quad
a_i^{\mathsf{T}} x \leq h_i \ \ \text{za sve } a_i \in \mathcal{P}_i, \ i = 1, 2.
\label{eq:rob_polazni}
\end{equation}
Ograničenja u~\eqref{eq:rob_polazni} predstavljaju beskonačno mnogo nejednakosti i ekvivalentna su uvjetima
\begin{equation}
\sup_{a_i \in \mathcal{P}_i} a_i^{\mathsf{T}} x \leq h_i, \qquad i = 1, 2.
\end{equation}

\subsection{Ekvivalentan problem s konačno mnogo nejednakosti}

Skupovi $\mathcal{P}_i$ su poliedri, točnije konveksne ljuske svojih vrhova, $\mathcal{P}_i = \mathrm{co}\big(v_i^{(1)}, \dots, v_i^{(4)}\big)$. Linearna funkcija $a \mapsto a^{\mathsf{T}} x$ na konveksnoj ljusci poprima maksimum u nekom od generatora: ako je $a = \sum_k \gamma_k v_i^{(k)}$ uz $\gamma_k \geq 0$, $\sum_k \gamma_k = 1$, tada iz $\big(v_i^{(k)}\big)^{\mathsf{T}} x \leq h_i$ za sve $k$ slijedi
\begin{equation}
a^{\mathsf{T}} x = \sum_k \gamma_k \big(v_i^{(k)}\big)^{\mathsf{T}} x \leq \sum_k \gamma_k h_i = h_i .
\end{equation}
Obrat je neposredan jer su vrhovi elementi skupa $\mathcal{P}_i$. Zato je robusno ograničenje egzaktno ekvivalentno konačnom skupu nejednakosti u vrhovima~\cite[str.~13--14]{jokic2025robusno}:
\begin{equation}
\sup_{a_i \in \mathcal{P}_i} a_i^{\mathsf{T}} x \leq h_i
\iff
\big(v_i^{(k)}\big)^{\mathsf{T}} x \leq h_i, \quad k = 1, \dots, 4.
\end{equation}

Svaki pravokutnik ima $2^2 = 4$ vrha, pa se dobiva ukupno $8$ linearnih nejednakosti:
\begin{equation}
\begin{aligned}
-0.85 x_1 - 0.85 x_2 &\leq -10, &\qquad 0.85 x_1 - 0.85 x_2 &\leq 3, \\
-0.85 x_1 - 1.15 x_2 &\leq -10, &\qquad 0.85 x_1 - 1.15 x_2 &\leq 3, \\
-1.15 x_1 - 0.85 x_2 &\leq -10, &\qquad 1.15 x_1 - 0.85 x_2 &\leq 3, \\
-1.15 x_1 - 1.15 x_2 &\leq -10, &\qquad 1.15 x_1 - 1.15 x_2 &\leq 3.
\end{aligned}
\label{eq:rob_osam}
\end{equation}
Robusni problem je time postao obični kvadratni program
\begin{equation}
\min_{x} \ \tfrac{1}{2} x^{\mathsf{T}} Q x + c^{\mathsf{T}} x \quad \text{uz} \quad G_{\mathrm{rob}} x \leq h_{\mathrm{rob}},
\label{eq:rob_qp}
\end{equation}
gdje je $G_{\mathrm{rob}} \in \mathbb{R}^{8 \times 2}$ sastavljena od vrhova, a $h_{\mathrm{rob}} = [-10, -10, -10, -10, 3, 3, 3, 3]^{\mathsf{T}}$.

\subsection{Analitičko rješenje i provjera KKT uvjeta}

Pretpostavimo da optimum leži u pozitivnom kvadrantu, $x_1 \geq 0$, $x_2 \geq 0$; pretpostavka se provjerava naknadno. Tada je od četiri nejednakosti prvog ograničenja najrestriktivnija ona s najmanjim iznosima koeficijenata, a od četiri nejednakosti drugog ograničenja ona koja maksimizira lijevu stranu:
\begin{align}
-0.85 x_1 - 0.85 x_2 &\leq -10 \iff x_1 + x_2 \geq \frac{200}{17} = 11.764706, \label{eq:rob_wc1} \\
1.15 x_1 - 0.85 x_2 &\leq 3. \label{eq:rob_wc2}
\end{align}

Ako bi u optimumu bilo aktivno samo~\eqref{eq:rob_wc1}, rješenje bi bilo $x = [6.9073,\ 4.8574]^{\mathsf{T}}$, no tada je
\begin{equation}
1.15 (6.9073) - 0.85 (4.8574) - 3 = +0.8146 > 0,
\end{equation}
pa točka nije dopustiva za~\eqref{eq:rob_wc2}. Time je isključen kandidat s aktivnim samo prvim najgorim ograničenjem. Kao sljedeći kandidat uzima se sjecište granica obaju najgorih ograničenja. Iz sustava
\begin{equation}
\begin{cases} 0.85 x_1 + 0.85 x_2 = 10 \\ 1.15 x_1 - 0.85 x_2 = 3 \end{cases}
\end{equation}
zbrajanjem slijedi $2 x_1 = 13$, odnosno
\begin{equation}
x_{\mathrm{rob}}^* = \begin{bmatrix} 13/2 \\ 179/34 \end{bmatrix} = \begin{bmatrix} 6.500000 \\ 5.264706 \end{bmatrix}, \qquad
f(x_{\mathrm{rob}}^*) = \frac{978253}{11560} = 84.623962.
\label{eq:rob_rjesenje}
\end{equation}
Obje su komponente pozitivne, čime je početna pretpostavka potvrđena. Optimalnost kandidata slijedi tek iz provjere KKT uvjeta u nastavku.

U toj točki gradijent funkcije cilja iznosi $\nabla f(x_{\mathrm{rob}}^*) = [13.420588,\ 16.108824]^{\mathsf{T}}$, a uvjet stacionarnosti uz dva aktivna vrha daje
\begin{equation}
\nabla f(x_{\mathrm{rob}}^*) + \mu_1^* \begin{bmatrix} -0.85 \\ -0.85 \end{bmatrix} + \mu_7^* \begin{bmatrix} 1.15 \\ -0.85 \end{bmatrix} = 0
\implies \mu_1^* = 17.607439, \quad \mu_7^* = 1.344118,
\end{equation}
oba strogo pozitivna. Preostalih šest nejednakosti iz~\eqref{eq:rob_osam} strogo je zadovoljeno, kako pokazuje tablica~\ref{tab:rob_vrhovi}. Time su svi KKT uvjeti zadovoljeni i $x_{\mathrm{rob}}^*$ je globalni optimum robusnog problema.

\subsection{Rješenje u MATLAB-u}

Matrica $G_{\mathrm{rob}}$ gradi se prolaskom kroz sve kombinacije skalirajućih faktora $0.85$ i $1.15$ za oba koeficijenta svakog retka, a dobiveni kvadratni program rješava se funkcijom \texttt{quadprog}.

\begin{lstlisting}
sc = [0.85, 1.15];
G_rob = []; h_rob = [];
for i = 1:2
    for s1 = sc
        for s2 = sc
            G_rob(end+1, :) = [s1*G(i,1), s2*G(i,2)];
            h_rob(end+1, 1) = h(i);
        end
    end
end
[x_rob, ~, ef, ~, lam_rob] = quadprog(Q, c, G_rob, h_rob, ...
                                      [], [], [], [], [], opts);
\end{lstlisting}

\begin{lstlisting}[style=outputstyle]
exitflag  = 1
x_rob*    = [6.500000; 5.264706]
f(x_rob*) = 84.623962
max(G_rob*x - h_rob) = -2.793e-11
\end{lstlisting}

\subsection{Slučajne realizacije i usporedba s nominalnim rješenjem}

Za grafički prikaz generirano je $100$ slučajnih realizacija matrice koeficijenata, $a_{ij}^{(k)} = s_{ij}^{(k)} a_{ij}^0$ uz $s_{ij}^{(k)} \sim \mathcal{U}(0.85,\ 1.15)$. Generator je inicijaliziran s \texttt{rng(42)} radi ponovljivosti.

\begin{lstlisting}
rng(42);
viol_nom = 0; viol_rob = 0;
for k = 1:100
    Gk = G .* (0.85 + 0.30*rand(2,2));
    if any(Gk*x_nom - h > 1e-12), viol_nom = viol_nom + 1; end
    if any(Gk*x_rob - h > 1e-12), viol_rob = viol_rob + 1; end
end
\end{lstlisting}

\begin{lstlisting}[style=outputstyle]
krsenja za x_nom* : 54 / 100
krsenja za x_rob* : 0 / 100
\end{lstlisting}
